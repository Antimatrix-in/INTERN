Automated Weighted Score Formula

When a technical mentor evaluates an intern submission, each of the 5 criteria is rated from 0 to 100. The final score (0–100) is deterministically calculated as:

Total Score = (S₁·W₁ + S₂·W₂ + S₃·W₃ + S₄·W₄ + S₅·W₅) / 100
  • • S₁: Technical Implementation Score (0–100)
  • • S₂: Code Quality & Standards Score (0–100)
  • • S₃: Functional Deliverables Score (0–100)
  • • S₄: Documentation & Specs Score (0–100)
  • • S₅: Demo Video & Presentation Score (0–100)
